A make.fun bounty entry: one line in which a home Wi-Fi router excuses itself for dying at the climax of a movie.

`main.ts` writes the entry to `/output/entry.txt` (UTF-8, 1–200 characters, validated before writing and verified byte-for-byte on read-back).

> I didn't drop the connection — I fainted. Even routers can't handle that plot twist.
